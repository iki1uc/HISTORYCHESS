# 3) HISTORYCHESS · Replay‑Engine

HISTORYCHESS spielt sechs berühmte Schachpartien automatisch ab.  
Jede Partie besitzt:

- echte historische Züge  
- emotionale Beschreibung („Angstschweiß“)  
- automatischen Zug‑Flow  
- Tastatur‑Steuerung  
- Reset‑Funktion  
- Auswahl zwischen mehreren Partien
